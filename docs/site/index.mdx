`OxidizePdf.NET` provides managed APIs backed by the oxidize-pdf Rust engine. These guides target NuGet package **0.20.2**, which uses Rust core **5.5.5**.

Start with [installation and extraction](/quickstart), then check [versions and limits](/scope).

The [repository](https://github.com/bzsanti/oxidize-pdf-dotnet) contains feature guides and examples. Native runtime binaries are distributed with the [NuGet package](https://www.nuget.org/packages/OxidizePdf.NET/0.20.2).

For documentation inside a coding assistant, see [Context7](/context7).
